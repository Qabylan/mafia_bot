Телеграм бот популярной игры Мафия

main.py — Диспетчер игры
Регистрация: Позволяет игрокам зарегистрироваться, написав «готов играть» боту в ЛС.

Инициализация (/game): Проверяет количество игроков. Если участников меньше 5, 
бот автоматически добирает недостающих ИИ-игроков (robot0, robot1 и т.д.), чтобы запустить матч.

Игровой цикл (game_loop): Раз в 10 секунд (через sleep(10)) переключает состояние night (True/False), 
объявляет погибших, проверяет условия победы и вызывает функции автоматического голосования ботов (autoplay_citizen / autoplay_mafia).

Игровые команды: Принимает команды /kill (для мафии ночью) и /kick (для всех днем), проверяя права голосующего.

db.py — Хранилище данных (State Machine)
Выступает в роли «ведущего», который помнит всё. Хранит ID игрока, никнейм, роль (mafia/citizen), статус жизни (dead), 
статус голосования в текущем раунде (voted), а также счетчики голосов mafia_vote и citizen_vote.
